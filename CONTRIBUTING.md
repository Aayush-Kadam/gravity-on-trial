# Contributing

Preserve frozen Gate 0–M3 science, raw bytes, configurations and manifests. New physics or inference changes require a new versioned scientific validation campaign; interface work must not silently replace benchmark values.

Keep observed data, frozen validated results and interactive previews distinct. Every curve must retain its observation mask, assumptions, outcome and provenance. Failed/unsupported records remain visible; MAP penalties are never ordinary MLE evidence.

Run `python m4_check.py`, the regression suite documented in README, the session tests and the real browser workflows before claiming an interface release. Inspect screenshots and measured resources. Do not add credentials, public hosting, telemetry or redistributed astronomical data without explicit scope and rights review.
