# R0R baseline and blocker

R0 was PARTIAL because a source-only checkout lacked the normalized catalog and M2/M3 evidence tree. Apache-2.0 ownership approval, dependency/security remediation and a source-only publication inventory already existed. R0R is release recovery, not a new astrophysical milestone or redesign.

All 1,326 M3 and 87 M4 protected entries were verified before and after recovery. Historic shared README/ledger entries use their preserved archived bytes as before; other files remain in place. The original research tree, M1–M4 reports, R0 manifest and R0 review ZIP were not overwritten. Changes live in release/r0r_v1/. New reports/evidence live in docs/R0R_*.md and results/r0r/v1/.

Recovered requirements include a previously omitted owned-process helper, a real official-data/normalized-catalog path, complete M2/M3 regeneration, generated manifests and scientific figures, a first-run setup state, and actionable corrupt-evidence handling. Existing physics/inference functions and frozen scientific configurations are unchanged and source-hash checked. The source-only candidate now reconstructs its own evidence locally rather than requiring copied developer outputs.
