# R0 scientific claims audit

Reviewed the current README/application presentation code, deterministic interpretation strings, historical method/result reports, saved acceptance summaries, figure-generation labels/captions and the publication candidate text against frozen numerical inventories and primary literature. Historical reports remain dated claims about their milestones; new R0 findings supersede public-readiness status without erasing history. The software is not represented as peer-reviewed research because the source observations or reference methods were published.

| Claim/guardrail | Audit conclusion |
|---|---|
| 175 real galaxies, 3,391 radii, 361 negative gas rows | Supported by preserved source checks |
| Four model families | Supported as numerical implementations; not four exhaustive theories of gravity |
| Empirical RAR | Fixed empirical prescription, not all MOND/modified gravity |
| Optimizer convergence | Kept separate from model adequacy and scientific truth |
| MLE versus MAP | Full-mask criterion eligibility guarded; MAP penalties unranked |
| Identifiability/boundaries/unsupported/inconclusive results | Visible in app and inventories; not silently converted into winners |
| M3 headline 79/18/5/5 | Applies to 107 decisive baselines; all-175 inventory 79/18/29/49 remains explicit |
| 906 retained /52 flips /70 inconclusive transitions | Out of 1,028 valid physical comparisons, not theory probabilities |
| Robustness ranges | Fixed partly overlapping scenario spans, not posterior intervals |
| Discovery/peer review/elite-research superiority | No such project claim is justified or made |
| Public fresh-source application reproducibility | Not established; candidate README now states the gap first |

Scope is nearby SPARC late-type disk-galaxy rotation curves and published mass components. No cluster, cosmological, strong-lensing, relativistic-theory or full-universe discrimination was performed. Unknown radial covariance, noncircular motions/systematics, uncertain mass-to-light ratios/geometry and limited information restrict inference. Removing a halo changes a model term at held assumptions; it does not prove/disprove dark matter. No dark-matter disproof, modified-gravity proof or new gravitational law is claimed.

The contribution is an inspectable implementation, validation/robustness record and interface around established methods. Prior-art overlap remains substantial. Primary foundations: [SPARC](https://arxiv.org/abs/1606.09251), [NFW](https://arxiv.org/abs/astro-ph/9611107), [Burkert](https://arxiv.org/abs/astro-ph/9504041), [empirical RAR](https://arxiv.org/abs/1609.05917), [Li et al. nuisance fitting](https://arxiv.org/abs/1803.00022). Published conclusions in those papers are not adopted as new project findings.

Approved public-facing description: **Gravity on Trial is a computational astrophysics laboratory for inspecting observed galaxy rotation curves, comparing conditional model fits and exploring sensitivity to tested assumptions. Its validated local benchmark covers 175 SPARC galaxies; public source-only setup still requires a complete tested path to the benchmark evidence.**
