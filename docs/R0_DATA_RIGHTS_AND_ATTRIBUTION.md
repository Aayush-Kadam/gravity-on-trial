# R0 data rights and attribution

The [official SPARC site](https://astroweb.case.edu/SPARC/) requests citation of the master paper and points to original rotation-curve references. The official table headers credit the authors. No explicit blanket redistribution license was found in those inspected materials. Citation and public download access are not treated as permission to repackage all data. The [original paper](https://arxiv.org/abs/1606.09251) describes public data availability; its [arXiv deposit license](https://arxiv.org/licenses/nonexclusive-distrib/1.0/license.html) does not establish general downstream data or figure rights. Unrelated biomedical SPARC portals, the scholarly-publishing coalition and NASA-wide terms were not applied to this independently hosted compilation.

| Material | Evidence-scoped release treatment |
|---|---|
| Original mass-model tables | Explicit redistribution grant unestablished; exclude |
| Galaxy metadata/catalog | Same compilation/source boundary; exclude data-bearing copies |
| Individual galaxy files and archives | Exclude; official downloader only |
| Parsed/derived per-radius tables | Preserve privately; exclude pending clarification |
| Recomputed fitting results with embedded source arrays | Exclude whole data-bearing records, not just raw directory |
| Parameter-only derived tables | Authored analysis but reuse boundary not established; conservatively exclude pending review |
| Statistical aggregate summaries | Publish only concise original factual analysis with methodology/citation; no wholesale dataset copy; this is not a blanket legal determination |
| Generated scientific plots and UI screenshots carrying observations | Project rendering does not by itself clear all underlying content; keep in private audit until rights scope is resolved |
| Original astronomical images | None acquired for M4; exclude any later image without its own rights evidence |
| Source-provided example figures | Not included; obtain applicable permission/license before reuse |

The public candidate includes authoritative URLs and expected SHA-256 references only. The documented downloader was tested from an empty audit raw-data directory: all three official files downloaded and matched the frozen hashes. Original local scientific files were neither deleted nor altered. Source-only snapshot excludes the fetched audit copies too.

Credit Lelli, McGaugh & Schombert (2016), SPARC, plus the original observational references for any specific galaxy. Metadata Ref codes and original bibliography remain available in the full local Evidence Vault. No attribution is represented as endorsement. Permission-request draft: R0_DATA_PERMISSION_REQUEST_DRAFT.md; it is unsent. No third party was contacted.

Remaining technical consequence: the safe source-only candidate does not contain the existing benchmark/evidence tree. The downloader alone does not reconstruct that tree. A complete tested local regeneration workflow or a separately cleared benchmark bundle is required before claiming new-user flagship reproducibility. Resolving this is essential work outstanding, not an invitation to upload private research files.
